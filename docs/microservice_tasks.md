## 🐳 hw02 — Docker и Docker Hub  
**Цель:** Научиться упаковывать приложение в Docker-образ и публиковать его в Docker Hub.

### 📝 Описание / Шаги выполнения  
1. Создать минимальный сервис:
   - Порт: `8000`
   - HTTP-метод: `GET /health/`
   - Ответ: `{"status": "OK"}`

2. Собрать локально Docker-образ под архитектуру **linux/amd64**.

3. Запушить образ в Docker Hub.

### 📤 Выходные данные
- Имя репозитория и тег в Docker Hub
- Ссылка на GitHub с `Dockerfile` или сам файл

> ⚠️ **Важно:** При сборке на M1 указывайте платформу:  
> `docker build --platform linux/amd64 -t tag`

## ☸️ hw03 — Основы Kubernetes  
**Цель:** Научиться создавать минимальный сервис и деплоить его в Kubernetes.

### 📝 Описание / Шаги выполнения  
1. Создать сервис (аналогично hw02).
2. Собрать Docker-образ и запушить в Docker Hub.
3. Написать манифесты для развертывания в k8s:
   - **Deployment** (2 реплики, Liveness/Readiness пробы)
   - **Service**
   - **Ingress** (хост: `arch.homework`)
4. После деплоя запрос `GET http://arch.homework/health` должен возвращать `{"status": "OK"}`.

### ⭐ Задание со звездой
Добавить в Ingress правило с rewrite для пути:  
`/otusapp/{student name}/*` → сервис.

### 📤 Выходные данные
- Ссылка на GitHub с манифестами (в одной директории)
- URL для проверки работы сервиса
- Postman-коллекция для тестирования
